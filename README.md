# BARRO Alfarería — reversión web (proyecto académico)

Reversión del sitio de BARRO Alfarería hecha por **VEPS Studio** para la materia Gestión de Empresas de Diseño (Diseño de Interiores, UADE).

- **No es la tienda oficial.** El carrito funciona como demo, pero no se procesan compras ni pagos.
- Imágenes, productos, precios de referencia y textos institucionales: [barroalfareria.com.ar](https://www.barroalfareria.com.ar/).
- Sitio de una sola página (`index.html`), sin dependencias más allá de Google Fonts.
